# 📱 КАК СОБРАТЬ APK С ТЕЛЕФОНА (без ПК)

## Способ: GitHub Actions (100% бесплатный, работает с телефона)

GitHub бесплатно компилирует Android-приложения в облаке. Вам нужен только браузер на телефоне.

---

## Шаг 1: Создайте аккаунт GitHub (если нет)

1. Откройте https://github.com/signup в браузере телефона
2. Зарегистрируйтесь (бесплатно)

---

## Шаг 2: Создайте новый репозиторий

1. Нажмите **"+"** → **"New repository"**
2. Название: `SecurityGuard`
3. Поставьте галочку **"Add a README file"**
4. Нажмите **"Create repository"**

---

## Шаг 3: Загрузите файлы проекта

**Вариант A: Через браузер (по одному файлу)**

Для каждого файла в проекте:
1. В репозитории нажмите **"Add file" → "Upload files"**
2. Перетащите файлы (нужно сохранить структуру папок)
3. Нажмите **"Commit changes"**

**Вариант B: Через сайт github.dev (удобнее)**

1. Нажмите клавишу `.` на клавиатуре (или замените `github.com` на `github.dev` в URL)
2. Откроется онлайн-редактор
3. Создавайте папки и файлы прямо там
4. Ctrl+S для сохранения каждого файла

---

## Шаг 4: Запустите сборку

**Автоматический запуск:**
- Просто отправьте любой коммит (изменение файла) — сборка начнётся автоматически

**Ручной запуск:**
1. Перейдите во вкладку **"Actions"**
2. Слева выберите **"Build APK"**
3. Справа нажмите **"Run workflow"** → **"Run workflow"**

---

## Шаг 5: Скачайте APK

1. Перейдите во вкладку **"Actions"**
2. Нажмите на последний запуск (оранжевый/зелёный кружок)
3. Внизу страницы в разделе **"Artifacts"** будет файл **"SecurityGuard-APK"**
4. Нажмите на него — скачается ZIP с APK
5. Распакуйте ZIP и установите APK на телефон

⚠️ **Примечание:** APK будет подписан debug-ключом. При установке разрешите "Неизвестные источники".

---

## ⏱ Время сборки

- Первая сборка: ~5-10 минут (скачивает зависимости)
- Последующие: ~3-5 минут

---

## 🔧 Структура файлов для загрузки на GitHub

Загрузите ВСЕ файлы из проекта, сохранив структуру папок:

```
SecurityGuard/
├── .github/workflows/build.yml    ← ЭТОТ ФАЙЛ ЗАПУСКАЕТ СБОРКУ
├── build.gradle
├── settings.gradle
├── gradle.properties
├── gradle/wrapper/gradle-wrapper.properties
├── app/
│   ├── build.gradle
│   ├── proguard-rules.pro
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/com/securityguard/... (все .kt файлы)
│       └── res/... (все XML файлы)
```

---

## ❓ Проблемы и решения

| Проблема | Решение |
|----------|---------|
| "Artifacts" не виден | Сборка ещё идёт, подождите |
| Ошибка сборки | Проверьте что все файлы загружены и структура папок правильная |
| APK не устанавливается | Разрешите установку из неизвестных источников в настройках |

---

## 📌 Альтернативный способ (ещё проще)

Вместо ручной загрузки файлов, можно попросить AI-ассистента создать Pull Request 
или использовать GitHub CLI, но для телефона способ выше — самый надёжный.
