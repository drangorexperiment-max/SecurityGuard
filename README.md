# 🛡️ Security Guard — Android Security Suite

**Полнофункциональное Android-приложение для комплексной проверки безопасности устройства.**

## 📋 Функции

### 🔍 Сканер угроз
- **Быстрое сканирование** — проверка приложений, процессов и критических папок
- **Полное сканирование** — глубокая проверка всей файловой системы
- Эвристический анализ файлов (расширения, хеши, расположение)
- Проверка MD5/SHA-256 хешей по базе известных угроз
- Обнаружение скрытых и маскированных файлов
- Проверка двойных расширений, dropper-APK, DEX/SO файлов вне стандартных путей

### ⚙️ Монитор процессов
- Чтение `/proc/[pid]` для получения подробной информации о каждом процессе
- CPU usage, потребление памяти, количество потоков
- Количество открытых файлов и сетевых соединений на процесс
- Обнаружение root-процессов и процессов с подозрительными именами (frida, xposed, magisk, su)
- Возможность завершения процессов
- Фильтрация: все / пользовательские / подозрительные

### 🚀 Менеджер автозапусков
- Обнаружение Broadcast Receivers для 10 категорий событий:
  - BOOT_COMPLETED, USER_PRESENT, NETWORK, MEDIA, SMS, CALL, BATTERY, LOCATION, SCREEN, CUSTOM
- Оценка риска каждого автозапуска
- Определение источника установки (Play Store / sideload)
- Статистика по категориям

### 🌐 Мониторинг сети
- Чтение `/proc/net/tcp`, `/proc/net/tcp6`, `/proc/net/udp`, `/proc/net/udp6`
- Парсинг IP-адресов (IPv4 little-endian) и портов
- Определение приложения по UID
- Обнаружение подозрительных портов (4444, 5555, 1337, 31337, Metasploit, Back Orifice и др.)
- Определение Tor-соединений

### 📱 Анализатор приложений
- Полный анализ каждого установленного приложения:
  - Количество опасных и критических разрешений
  - Оценка риска (0-100)
  - Проверка на debuggable, allowBackup
  - Проверка targetSdkVersion (обход ограничений)
  - Анализ подписи APK (SHA-256)
  - Определение источника установки
  - Обнаружение SMS+Internet, Camera+Mic+Internet комбинаций
  - Поиск ключей трекеров в metadata
- Детальная страница каждого приложения
- Поиск и фильтрация по категориям

### 🔐 Менеджер разрешений
- Группировка всех опасных разрешений по приложениям
- Разделение на критические и опасные
- Сортировка по количеству приложений с данным разрешением

### 👁️ Проверка приватности
- Оценка приватности по 7 категориям:
  - Камера, микрофон, геолокация, звонки/контакты, SMS, хранилище, трекеры
- Подсчёт приложений с доступом к каждой категории
- Общая оценка приватности

### 📊 Рейтинг безопасности
- Комплексный score по 6 параметрам:
  1. Защита от вредоносного ПО
  2. Безопасность разрешений
  3. Сетевая безопасность
  4. Приватность
  5. Безопасность автозапусков
  6. Безопасность системы

### 🔧 Системные проверки
- Обнаружение Root-доступа (проверка su бинарников + попытка выполнения)
- Проверка ADB-отладки
- Проверка блокировки экрана
- Проверка неизвестных источников
- Проверка шифрования хранилища
- Проверка версии Android

### 🔔 Фоновые сервисы
- **ScanService** — фоновое сканирование с уведомлениями о прогрессе
- **MonitorService** — мониторинг процессов в реальном времени (30 сек интервал)
- **BootReceiver** — анализ автозапусков при загрузке устройства
- **AppInstallReceiver** — автоматическая проверка новых/обновлённых приложений

### 🗄️ База данных угроз
- Хеши известных вредоносных файлов (MD5)
- Известные spyware пакеты
- Известные adware пакеты
- Подозрительные подписи APK
- C2 (Command & Control) домены
- Расширяемая база (пользовательские хеши)

## 🏗️ Архитектура

```
├── engine/          # Ядро приложения
│   ├── ScanEngine        — главный движок сканирования
│   ├── ProcessEngine     — мониторинг процессов
│   ├── NetworkEngine     — мониторинг сети
│   ├── AutostartEngine   — анализ автозапусков
│   ├── SecurityScoreEngine — вычисление рейтинга
│   └── ThreatDatabase    — база данных угроз
├── model/           # Модели данных
├── service/         # Фоновые сервисы и приёмники
├── ui/              # Activities и UI
│   ├── MainActivity      — главная панель
│   ├── scanner/          — экран сканирования
│   ├── processes/        — монитор процессов
│   ├── autostart/        — менеджер автозапусков
│   ├── apps/             — анализатор приложений
│   ├── network/          — мониторинг сети
│   ├── permissions/      — менеджер разрешений
│   └── privacy/          — проверка приватности
└── util/            # Утилиты
```

## 📲 Сборка

1. Откройте проект в **Android Studio**
2. Синхронизируйте Gradle
3. Запустите сборку (Build > Build APK)

**Требования:**
- Android Studio Hedgehog или новее
- JDK 17
- Android SDK 34
- Min SDK 24 (Android 7.0)

## ⚠️ Важно

- Приложение запрашивает `QUERY_ALL_PACKAGES` для анализа всех установленных приложений
- Для полного сканирования файловой системы может потребоваться `MANAGE_EXTERNAL_STORAGE`
- Для мониторинга процессов требуется доступ к `/proc` (доступно на большинстве устройств)
- Сетевые данные читаются из `/proc/net/` — не требует специальных разрешений
- Для доступа к статистике использования приложений требуется `PACKAGE_USAGE_STATS`
